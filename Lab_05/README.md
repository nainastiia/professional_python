# Reliable Warehouse Importer & Exporter (Варіант 10)

Надійний Python-модуль для потокового імпортування, валідації та експорту даних складських запасів із підтримкою гнучкої конфігурації, обробки винятків та атомарного запису.

## Особливості реалізації
- **Потокове читання (Streaming I/O):** Ефективна обробка великих CSV-файлів за допомогою генераторів без завантаження всього обсягу в оперативну пам'ять (RAM).
- **Ієрархія винятків та Chaining:** Власні доменні винятки (`ApplicationError`, `DataImportError`, `RecordValidationError`, `ConfigurationError`) із збереженням першопричини через `raise ... from error`.
- **Політики обробки помилок:**
  - *Tolerant Mode:* Пропуск некоректних рядків з їх логуванням і продовження обробки.
  - *Strict Mode:* Миттєве переривання процесу при першій же помилці валідації.
- **Атомарний експорт (Atomic Write):** Запис результатів спочатку у тимчасовий файл (`.tmp`) з подальшою атомарною заміною оригінального файлу, що захищає дані від пошкодження у разі аварійного завершення програми.
- **Контекстні менеджери:** Безпечне управління ресурсами файлів та вимірювання часу виконання операцій.
- **Логування:** Детальна діагностика подій та попереджень про низькі запаси товарів (`low_stock_threshold`) за допомогою вбудованого модуля `logging`.

---

## Структура полів (Варіант 10)
Вхідний файл (`data/inventory.csv`) містить такі поля:
1. `code` — унікальний код товару (обов'язковий рядок).
2. `name` — назва товару (обов'язковий рядок).
3. `quantity` — кількість на складі (ціле число $\ge 0$).
4. `price` — ціна за одиницю (число з плаваючою комою $\ge 0$).
5. `category` — категорія товару (має належати до списку дозволених: `electronics`, `groceries`, `stationery`, `hardware`, `clothing`).
