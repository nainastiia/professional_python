
# Лабораторна робота №6
## Автоматизоване тестування Python-програм за допомогою pytest

**Варіант №10:** керування складськими запасами.

### Мета роботи

Ознайомитися з автоматизованим тестуванням Python-програм за допомогою
pytest, створити модульні та інтеграційні тести, перевірити нормальні,
граничні й помилкові сценарії та оцінити покриття коду.

### Функціональність

- створення товарів і складських позицій;
- перевірка ціни та кількості;
- надходження та видача товарів;
- обробка недостатнього залишку;
- пошук за кодом товару;
- розрахунок загальної вартості запасів;
- пошук товарів із низьким залишком;
- налаштування порога низького залишку;
- потоковий імпорт CSV;
- експорт даних у JSON;
- тестування залежностей через Mock і AsyncMock.

### Встановлення

Створи та активуй віртуальне середовище, потім виконай:

```bash
python -m pip install -e ".[test]"
```

### Запуск усіх тестів

```bash
python -m pytest -v
```

### Запуск із покриттям коду та гілок

```bash
python -m pytest -v --cov=warehouse --cov-branch --cov-report=term-missing --cov-report=html
```

### Результати покриття

HTML-звіт створюється в каталозі `htmlcov/`.
Відкрий `htmlcov/index.html` у браузері.

Мінімальний поріг покриття, встановлений у конфігурації: 80%.
Фактичний результат визначається після запуску тестів.
