# Лабораторна робота №4: Професійне ООП та система типів Python

**Система обліку складських запасів (Варіант 10)**

## Мета роботи
Сформувати практичні навички побудови професійної об'єктно-орієнтованої моделі в Python із використанням класів, композиції, наслідування, абстрактних базових класів (ABC), протоколів (Protocol), `dataclass`, властивостей (`properties`), dunder-методів, принципів SOLID та сучасної системи типів (`type hints`, `Generic`, `TypeVar`, `TypedDict`).

---

## Архітектура та структура проєкту

Проєкт організовано відповідно до сучасних стандартів проєктування модульних Python-додатків:

```text
warehouse_project/
│
├── pyproject.toml         # Конфігурація проєкту та налаштування mypy
├── README.md              # Документація проєкту
└── src/
    └── warehouse/
        ├── __init__.py
        ├── value_objects.py  # Незмінні об'єкти-значення (frozen dataclass)
        ├── models.py         # Доменні сутності, ABC-операції, контейнери
        ├── protocols.py      # Структурні інтерфейси (Protocol)
        ├── dto.py            # Зовнішні структури даних (TypedDict)
        ├── repositories.py   # Універсальний дженерик-репозиторій
        ├── services.py       # Бізнес-логіка та ін'єкція залежностей (DI)
        └── main.py           # Точка входу та демонстраційний сценарій
