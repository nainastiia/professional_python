# Аналіз системи обліку складських запасів (Варіант 10)

Лабораторна робота з дисципліни програмування (структури даних та функціональна декомпозиція).

## Мета роботи
Сформувати практичні навички професійного використання базових та розширених структур даних Python (`list`, `tuple`, `set`, `dict`, `collections`), реалізувати генератори (*comprehensions*), функціональну декомпозицію, використання `*args`, `**kwargs`, `lambda`, замикань (*closures*), декораторів, а також виконати оцінку алгоритмічної складності (Big-O).

## Функціонал програми
- Облік та зберігання товарів на складі (`list`, `dict`).
- Використання метаданих складу (`tuple`).
- Отримання унікальних категорій товарів (`set comprehension`).
- Групування та підрахунок позицій через `defaultdict` та `Counter`.
- Фільтрація даних за допомогою *list comprehensions* та замикань (*closures*).
- Агрегація даних (обчислення загальної вартості складу).
- Вимірювання часу виконання за допомогою кастомного декоратора.
- Експериментальний бенчмарк для порівняння швидкості пошуку в `list` та `dict`.
