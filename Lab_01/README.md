# Warehouse System

Консольний застосунок для обліку складських запасів (Варіант 10) з дисципліни «Професійний Python»[cite: 1].

## Вимоги
- Python 3.11+[cite: 1]

## Встановлення
```bash
python -m venv .venv
# Активуйте віртуальне середовище (.venv\Scripts\activate або source .venv/bin/activate)
python -m pip install -e .
```

## Запуск
```bash
python -m warehouse_system.main
```
